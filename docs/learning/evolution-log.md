# Learning-Memory Evolution Log

This clean template contains **no migration learning events**.

During a real program, append entries in the following form without rewriting prior decisions:

```text
## [YYYY-MM-DDTHH:MM:SSZ] <observe|consolidate|propose|validate|promote|reject|rollback> | <identifier>

- Evidence: <repository-relative path and SHA-256>
- Actor role: <role>
- Outcome: <PASS|FAIL|BLOCKED|APPROVED|REJECTED>
- Summary: <observable result>
```

Do not include private reasoning, secrets, raw business data, or unredacted prediction values.
