# Learning Records

Learning records capture repeated evidence, not impressions. A single incident becomes a regression case. Only repeated independent evidence may become a candidate reusable pattern or skill change. Promotion requires normal and pressure tests, independent review, and human approval.

| File or directory | Purpose |
|---|---|
| `WIKI_CONTRACT.md` | Authority, privacy, recurrence, validation, and promotion rules |
| `index.md` | Navigation catalog for active pattern pages |
| `evolution-log.md` | Append-only chronology of observation, consolidation, proposal, and decision events |
| `skill-impact.md` | Accepted, rejected, and rolled-back proposal history |
| `patterns/` | Evidence-backed pattern pages created during real programs |
| `artifacts/learning/reviews/` | Independent machine-readable rerun records bound to exact candidate commits |

The clean reusable template keeps the index and logs empty. The learning memory is advisory and cannot override approved project contracts.
