# Local Intake

Place original SAS programs, logs, LST files, approved inputs, trusted outputs, manifests, and optional source-pattern bundles in the matching subdirectories. Their contents are ignored by Git in this public template.

Do not edit source artifacts or generated outputs to compensate for missing evidence. Start with `/start-migration new <MODULE-ID>` in GitHub Copilot Agent Mode. The authorized intake skill may inventory and hash files, but it must not execute untrusted source material.

See [`REQUESTED_ARTIFACTS.md`](REQUESTED_ARTIFACTS.md) for the adaptable source checklist.
